# МедАрхив — Система управления архивом медицинских карт

Веб-приложение для учёта медицинских карт в архиве организации с несколькими филиалами.

**Стек прототипа:** Python 3.11+ · FastAPI · Jinja2/HTMX · SQLite

> **Статус целевой версии:** проект переводится на PostgreSQL. SQLite-версия ниже описывает исходный прототип и пока остаётся запускаемой, но не является целевой архитектурой. PostgreSQL-адаптер и Alembic подготовлены; маршруты и репозитории ещё не переключены. Для настройки целевого PostgreSQL см. [инструкцию разработчика](docs/development/postgresql.md). Не используйте инструкции SQLite ниже как инструкцию развёртывания целевой версии.

## Возможности

- **Упаковка карт в коробки** — сканером штрих-кодов, автодополнение ФИО
- **Передача курьеру** — выбор курьера, фиксация отправки
- **Приёмка и размещение** — в архиве, с выбором секции/полки
- **Возврат по заявкам** — одиночная карта или коробка возврата
- **Поиск** — по ФИО пациента или номеру коробки, с историей движений
- **Дашборд** — статистика в реальном времени
- **QR-печать** — наклейки для полок архива (сетка A4)
- **Бэкап/восстановление** — ручной и автоматический по расписанию

## Роли

| Роль | Доступ |
|------|--------|
| **Филиал** | Упаковка, передача курьеру, заявки на возврат, приём возврата |
| **Архив** | Приёмка, размещение, очередь заявок, поиск, перестановка |
| **Просмотр** | Дашборд, поиск, журнал движений (без изменений) |
| **Админ** | Полный доступ + справочники, QR, бэкап, инциденты |

## Установка

### Требования

- Python ≥ 3.11
- pip

### 1. Клонировать и установить зависимости

```bash
git clone <repo-url> /opt/medarchive
cd /opt/medarchive
pip install .
```

### 2. Сгенерировать секретный ключ

```bash
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
```

### 3. Настроить переменные окружения

```bash
export MEDARCHIVE_SECRET_KEY="сгенерированный-ключ"
export MEDARCHIVE_DB_PATH="/var/lib/medarchive/medarchive.db"  # по умолчанию medarchive.db в CWD
```

### 4. Инициализировать БД и создать админа

```bash
python3 -c "
import asyncio
from medarchive.main import create_app
from medarchive.config import Config

async def init():
    config = Config()
    from medarchive.dependencies import init_dependencies, get_db
    init_dependencies(config)
    db = await get_db()
    await db.init()
    # Создать админа
    import bcrypt
    pwd = bcrypt.hashpw(b'admin', bcrypt.gensalt()).decode()
    await db.execute(\"INSERT OR IGNORE INTO users (username, password_hash, role) VALUES ('admin', ?, 'admin')\", (pwd,))
    await db.conn.commit()
    print('БД инициализирована. Логин: admin / пароль: admin')

asyncio.run(init())
"
```

### 5. Запустить

```bash
uvicorn medarchive.main:create_app --factory --host 0.0.0.0 --port 8000
```

### 6. (Опционально) Установить как systemd-сервис

```bash
sudo bash scripts/install.sh
```

Сервис будет запущен и включён в автозагрузку.

## Администрирование

### Справочники (`/admin`)

Доступны только роли **admin**:
- **Филиалы** — создание, переименование, удаление
- **Пользователи** — создание, смена роли/пароля, удаление
- **Курьеры** — создание, редактирование, удаление
- **Секции и полки** — структура архива + QR-коды для наклеек
- **Инциденты** — ручной разбор потерянных/повреждённых коробок

### Бэкап и восстановление (`/admin/backup`)

**Ручной:** кнопка «Скачать бэкап» → файл сохраняется локально. Восстановление — загрузить `.db` файл с подтверждением (перед восстановлением автоматически создаётся бэкап текущего состояния).

**Автоматический:** после установки systemd-сервиса — ежечасные копии БД в `/var/lib/medarchive/backups/`, хранение 24 шт.

### Восстановление из бэкапа

```bash
# Остановить сервис
sudo systemctl stop medarchive

# Заменить БД
sudo cp /var/lib/medarchive/backups/medarchive-2026-08-07T12:00:00.db /var/lib/medarchive/medarchive.db

# Запустить
sudo systemctl start medarchive
```

## QR-печать полок

1. Зайти в `/admin/sections`
2. Создать секции и полки
3. Нажать «🖨️ Печать QR полок» — откроется страница с сеткой наклеек A4
4. Распечатать, разрезать, наклеить на физические полки

При размещении коробки архивариус сканирует QR полки — и коробка автоматически назначается на нужное место.
