# UX-07 — детальные состояния непрерывного QR-сканирования филиала

**Дата:** 2026-11-23. **Статус:** второй low-fi проход; решение об автоматическом создании карты утверждено. Документ описывает визуальные и интеракционные состояния для будущего UX-08, не реализует их.

Основание: `UX-07-WF-08-CONTINUOUS-QR-SCANNING.md`, `UX-07-WF-01-BRANCH-WIREFRAMES.md`, `UX-07-UNIFIED-SCREEN-MAP-AND-NAVIGATION.md`.

## Экран Q1. Поточная регистрация карт

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ Филиал → Карты                                ● Сканер готов              │
│                                                                            │
│                   [▣] Сканируйте QR следующей карты                        │
│          Каждое считывание автоматически ищет или создаёт карту           │
│                                                                            │
│ Последнее действие  ✓ Карта №... зарегистрирована                          │
│ Сегодня в этой рабочей сессии: 12 успешно · 1 требует внимания            │
│                                                                            │
│ Последние сканы                  Результат          Время                  │
│ №...                             Создана            ...                    │
│ №...                             Уже существует     ...                    │
│                                                                            │
│ Дополнительно: [Поиск по ФИО] [Создать вручную] [Камера]                    │
└────────────────────────────────────────────────────────────────────────────┘
```

**Нет** кнопки «Сканировать» как обязательного шага. Сканирование не помещает карту в коробку. Числа/имена — демонстрационные.

## Экран Q2. Поточное наполнение открытой коробки

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ Филиал → Коробки → BX-125                    ● Сканер готов               │
│                                                                            │
│ КОРОБКА BX-125  ·  В коробке 24 карты  ·  Черновик/состав доступен          │
│                                                                            │
│                   [▣] Сканируйте QR следующей карты                        │
│           Карта будет добавлена именно в коробку BX-125                   │
│                                                                            │
│ Последний скан: ✓ №... · Новая карта создана и добавлена                   │
│                                                                            │
│ [Состав коробки] [Последние сканы] [Требуют внимания: 1]                   │
│ Дополнительно: [Поиск по ФИО] [Создать вручную]                             │
│                                                                            │
│ [Вернуться к коробкам]                          [Оформить отправление]    │
└────────────────────────────────────────────────────────────────────────────┘
```

**Контекст коробки должен быть заметнее, чем декоративная статистика.** Нельзя допустить добавления в незаметно сменившуюся коробку. После ручного добавления или закрытия формы сканер снова готов.

## Экран Q3. Конфликт / потенциальный дубль

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ⚠ Требуется проверка: QR №...                                             │
│ Обнаружена другая карта с похожим ФИО                                      │
│                                                                            │
│ Сканируемая карта: №... / ФИО / дата рождения                              │
│ Возможное совпадение: №... / ФИО / дата рождения                           │
│                                                                            │
│ [Подтвердить отдельную карту] [Отложить разбор] [Отменить]                  │
│                                                                            │
│ Состояние сканера: готов к следующим QR; проблемный скан сохранён         │
│ только как рабочий результат сессии, не как созданная карта               │
└────────────────────────────────────────────────────────────────────────────┘
```

При одинаковом номере, но конфликте ФИО/ДР, **нет** кнопки «Создать всё равно»: требуется отдельная разрешённая корректировка. Никаких автоматических изменений существующей карты.

## Экран Q4. Ошибка сети и неопределённый результат

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ! Результат сканирования №... пока не подтверждён сервером                │
│                                                                            │
│ [Проверить результат] [Повторить безопасно]                                 │
│                                                                            │
│ Не показывать «Карта создана» до подтверждения commit.                     │
│ Повтор должен использовать тот же идентификатор операции.                 │
└────────────────────────────────────────────────────────────────────────────┘
```

Нельзя слепо повторять создание по новому идентификатору после тайм-аута: сначала запросить сохранённый результат операции.

## Экран Q5. Узкая ширина / мобильная камера

```text
┌──────────────────────────────────────┐
│ ☰  Филиал / BX-125                   │
│ ● Сканер готов                       │
│                                      │
│ В коробке: 24 карты                  │
│ [▣ Сканируйте QR]                    │
│                                      │
│ ✓ Последняя карта добавлена          │
│ [Состав] [Ошибки: 1]                 │
│                                      │
│ [Поиск по ФИО]                       │
│ [Создать вручную]                    │
│ [Включить камеру]                    │
└──────────────────────────────────────┘
```

Для камеры нужно явное разрешение браузера, но **не** повторное нажатие кнопки для каждого следующего QR в активной сессии камеры. HID-сканер не требует разрешения камеры.

## Матрица переходов и приоритетов

| Состояние | Что видит сотрудник | Что происходит при следующем QR |
|---|---|---|
| Готов | Зелёный/нейтральный индикатор и контекст | Принимается новый скан |
| Обрабатывается | Индикатор прогресса, текущий scan_id | Добавляется в ограниченную очередь |
| Успех: создана | Номер и «создана»; в коробке также «добавлена» | Следующий скан без клика |
| Успех: найдена | «Уже существует» / «добавлена» | Следующий скан без клика |
| Повтор в той же коробке | «Уже в коробке»; счётчик не меняется | Следующий скан без клика |
| Потенциальный дубль | Элемент «Требует внимания» | Следующий скан не подтверждает старый автоматически |
| Неверный QR | Ошибка формата/версии без PII | Следующий скан без клика |
| Нет доступа / конфликт | Безопасная причина, без мутации | Следующий скан без клика |
| Сеть недоступна | «Результат не подтверждён» | Контролируемая пауза/очередь, без ложного успеха |
| Ручная форма в фокусе | Сканер не перехватывает текст | QR не вставляется в ФИО/комментарий |
| Смена коробки | Новый контекст виден явно | Только новая коробка; старые операции не перенаправляются |

## Обязательные проверки перед UX-08

1. Реальное оборудование: USB/Bluetooth HID, Enter/CRLF, разные раскладки и скорость ввода, длинный JSON с кириллицей; браузерная среда и фокус.
2. 30+ последовательных сканов, в том числе новые/существующие/повторные; отсутствие потерь и двойных membership.
3. Подозрительные совпадения ФИО требуют подтверждения отдельной карты; штатные новые карты **не требуют** подтверждения.
4. Сканирование в разделе «Карты» никогда не добавляет карту в коробку; в режиме коробки всегда привязано к видимой коробке.
5. Не обещать различение HID от обычной клавиатуры только по скорости ввода.
6. Обязательна серверная атомарность, idempotency и повторная проверка scope; frontend-индикатор не является подтверждением сохранения.
7. Проверить keyboard focus, контраст, звуковые сигналы как дополнение, а не единственный канал обратной связи.
8. Встроить Q1/Q2 в визуальные макеты филиала следующей итерации; прежний SVG первого прохода не считать финальным.
