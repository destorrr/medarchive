# UX-08-06 — уточнение доступа к аналитике

Последнее решение владельца продукта заменяет ограничение только ЦО в UX-08-ANALYTICS-V4-APPROVED-BASELINE.md и X01 в UX-08-06-CROSS-PROTOTYPE-REVIEW.md. Активным сотрудникам ЦО и архива администратор может назначать и отзывать dashboard_view; по умолчанию нет. Активным администраторам доступ всегда; филиалам нет. Назначение и отзыв аудируются. Черновики admin v5 и analytics v5 отражают изменение. При переходе между ЦО и архивом черновик сохраняет право, при переходе в другие роли отзывает назначенное право; это техническое предложение, не отдельное согласование. Область данных и объектная авторизация требуют проверки. Утверждённые HTML не изменены; браузерные и серверные тесты не проводились.
