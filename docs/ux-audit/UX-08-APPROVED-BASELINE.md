Последние решения: филиал — период создания отправлений; ЦО — принятые архивом коробки исключены из рабочего списка, история сохраняется; архив — текущие и завершённые реестры, период создания для истории, старые незавершённые не скрываются. P-09: одна передача всех готовых карт, ответственность курьера после передачи до получения каждой карты ЦО. dashboard_view назначается активным сотрудникам ЦО и архива; администратор имеет доступ всегда. Даты создания и история сохраняются.

Все пять JS проверены на синтаксис. Изолированные тесты не заменяют браузерные, HID, responsive/keyboard, серверные транзакции, права и сквозную синхронизацию. UX-08 product baseline согласован; технические exit gates остаются открытыми. Production-код не меняется. Старые утверждённые версии сохраняются в Git history, не в текущем каталоге prototypes.
