## Read models / adapters
Proposed RoleHomeSummary, AnalyticsQueueSummary, AnalyticsMovementSeries, AnalyticsQueueDetail, StorageExplorer, StorageBoxDetail. GET read only; scope first, typed filter allowlist, stable ordering, bounded pagination, full filtered aggregate not page count. Consistent snapshot for summary+rows; if separate requests show as_of and refresh on change. No patient PII in generic queues/charts. Storage visual/table same predicate: section/shelf/placement/box number; preserve filters and selection, sort by box number or card count. Actual hierarchy section→shelf→box→card, no room/rack invented. Current membership only; box detail number/FIO only under independent authorization. Empty box valid; P09 extracted cards not on shelf. 
Existing /dashboard, /search, /search/results, /history routes verified; universal dashboard and global history need role-specific replacement, not new global feed. General card search FIO only; specialized packing search conflict tracked B. Proposed analytics GET endpoints separate from role home; no demo setRole or synthetic multipliers. PostgreSQL query/index design after schema mapping, EXPLAIN with representative data; no materialized views until measured need.
