## Declarative constraints and indexes (proposed)
PK/FK RESTRICT for history, NOT NULL where unconditional, CHECK for local status/actor-time pairs and external custody fields, unique card/box number, normalized courier FIO, login, branch location and singleton CO/archive. Partial UNIQUE active cycle per box, membership per card, placement per box, reservation_active per card. UNIQUE shipments.request_id and shipment_cards.request_item_id; composite manifest PK; never global UNIQUE historical card_id. Active ordinary draft reservation: separate current reservation relation or maintained flag with partial unique box_id (choose in DDL after existing index review). No cross-table CHECK or partial-index JOIN. Deferred constraint guards enforce cross-table final state; immediate guards protect immutable identity/history. Proposed lookup indexes: FK child keys, request status/created_at/id, shipment destination/status/created_at/id, event aggregate/time/id, audit time/id, shelf active placement, card normalized FIO prefix strategy benchmark (not arbitrary substring). Avoid redundant indexes; EXPLAIN with synthetic data.
## Transaction protocol
UX06 approved envelope: actor from authenticated session, command_id, correlation_id, typed business parameters; result_code/version/payload/command_id/correlation_id/completed_at. Unique ledger key, canonical input fingerprint, exact committed result, no committed in_progress; replay checks actor/type/input and current read permission, not original business preconditions. No PII in generic errors or logs. All state/event/audit/ledger atomic; response only after commit. Unexpected SQL failure rollback, bounded retry only for retryable SQLSTATE with same command ID. 
Lock principal and relevant scope/grants first, stable UUID; grant/revoke/deactivation share locks. P09 parent→shipment→items→cards/memberships/boxes per DB73. Other families use root and stable resource order; cross-family collision (packing vs P09, shipment vs placement, writeoff vs reservation) requires explicit lock graph before coding. Do not claim one global order already proven. Discover resource set, lock, recheck; restart if set changed. Unique indexes are final concurrency backstop. Last-admin race requires common serialization lock (proposed singleton guard or transaction advisory lock); verify no bypass.
