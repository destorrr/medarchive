## Findings
F01 backup.sh uses runtime URL; separate read-only backup principal and credential file, no runtime/migrator membership. F02 dump --no-owner --no-acl and restore --no-owner --no-acl: data restore alone does not restore security; provision principals and reapply versioned ownership/ACL policy, verify SECURITY DEFINER owner and effective privileges before app start. F03 CI push branches master/docs/target-architecture-spec only; PR master only; add active implementation branch or PR target and manual dispatch as appropriate. F04 compose PG16 demo credentials and all-interface 5432 mapping; development only, bind loopback by default, production network private. F05 systemd Uvicorn 0.0.0.0:8000; proposed loopback behind TLS reverse proxy, trusted proxy headers only, no direct public access. F06 install creates root:medarchive 0640 env and 0700 data/backup dirs; app and backup share OS account/env; separate backup account and directory access proposed. F07 backup temporary plaintext dump and pgpass cleaned by EXIT trap but abrupt termination can leave files; detect stale temporary artifacts, restricted storage, controlled cleanup, no secret logging. F08 install enables timer based on partial config validation, does not prove migration/restore readiness; explicit deployment gates. F09 CI uses initial PG superuser for migrations/tests/backup; cannot prove runtime ACL; provision separate roles and exercise each identity. F10 CI restore only checks table presence, not data/ACL/function behavior.

## Backup/restore
Preserve hourly timer, 24 local copies as existing defaults, age encryption, flock, pg_restore --list, atomic publication and rotation only after success. Separate backup role needs read access to all required data including audit/ledger and sequences; verify RLS behavior and complete dump, no silent omissions. Restore isolated PG16 using controlled restore identity; provision roles, restore data/schema, reapply ownership and ACL from versioned policy, verify counts, constraints, event history, functions, negative runtime DML and application smoke. Do not rerun migrations blindly over restored head. Test interrupted backup, wrong key, missing privilege, disk failure, stale temp files, off-host retrieval. No real patient data in CI.
