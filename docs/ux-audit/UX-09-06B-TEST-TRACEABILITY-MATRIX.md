## Cross-cutting execution
Unit tests for pure normalization and projections; real PG16 integration for constraints, commands, commit-time deferred guards; independent connections and explicit synchronization for races (not sleep-only); HTTP tests for session/role/scope/CSRF/replay and direct endpoint denial; Playwright for real workflows; physical HID manual evidence. Use synthetic data only. Inject failure before final commit, assert aggregate, events, audit and ledger all unchanged. Verify both winner orders in conflicting operations, no deadlock or bounded retry with same command ID. No mock-only acceptance of DB invariants.
## End-to-end scenarios
E2E1 branch creates cards by QR/manual, packs, hands over, archive receives one box at a time, places and regroups; verify history and custody at each boundary. E2E2 CO requests multiple cards, archive extracts all, records exceptions, creates one full ready manifest, hands over once, CO receives in stages; parent completes only last receipt, exceptions preserved. E2E3 CO returns cards to archive in boxes; external custody blocks packing until return. E2E4 admin grants/revokes access while another session operates; verify no stale privilege, audit and read isolation. E2E5 backup/restore isolated then repeat representative workflows and negative ACL.
